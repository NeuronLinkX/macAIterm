# SSH: 서버 접속, 서버 모니터, 파일 트리

터미널 탭에서 `ssh` 로 서버에 들어가면 MacAIterm 이 그 접속을 알아보고 세 가지를 더해 줍니다.

1. **서버에서 일하는 AI**: 명령 실행·파일 읽기/수정/생성·검색이 모두 *서버*에 적용됩니다(변경은 서버 이름이 적힌 승인을 받습니다).
2. **서버 사용량**: 서버의 CPU · 메모리 · GPU · 디스크가 탭 아래 띠에 표시되고, **이 Mac 의 사용량은 상단 바에 그대로** 있어 둘을 동시에 봅니다.
3. **왼쪽 사이드 바**: 세션 관리자(저장·폴더·가져오기), **서버와 이 Mac 의 폴더 트리**(드래그로 복사), 서버 상태 패널.

## 빠른 시작

1. 왼쪽 막대의 **서버 아이콘**(세션)을 엽니다. `~/.ssh/config` 의 호스트, 최근 접속, 저장한 세션이 보입니다.
2. 세션을 **더블클릭**하면 새 탭에서 접속합니다(Alt+더블클릭: 지금 탭에서). **`+ 새 세션`** 으로 직접 만들 수도 있습니다.
3. 비밀번호(또는 키 암호)는 **터미널에서 직접 입력**합니다. 앱은 비밀번호를 묻지도, 저장하지도 않습니다.
4. 접속되면 칩에 `SSH · 서버이름`, 탭 아래에 서버 사용량 띠, 왼쪽에 폴더 트리가 나타나고, 타임라인에 *"이 서버에서 AI 로 작업할까요?"* 제안이 뜹니다. 터미널에서 직접 연 `ssh user@host` 도 똑같이 인식합니다.

## 서버에서 일하는 AI

- **켜기**: 접속 직후의 제안에서 `AI 를 서버에서 작업시키기`, 하단의 `원격` 토글, 또는 칩을 눌러 `AI 가 서버에서 작업`. 설정(SSH · 원격)에서 *물어보기 / 자동 전환 / 안 함* 을 고릅니다.
- **무엇이 일어나나**: 서버의 셸 종류(bash·zsh·sh·fish·csh), OS, 홈, 현재 폴더를 알아낸 뒤 AI 의 문맥을 *서버 기준*으로 바꿉니다(이 Mac 의 프로젝트 정보는 섞이지 않음). 명령은 **사용자가 보는 그 터미널**에 입력되어 실행되고(보이는 대로 실행), 종료 코드와 `cd` 로 바뀐 폴더를 추적합니다.
- **파일 도구**: `read_file` / `search` / `edit_file` / `write_file` 도 서버 파일에 적용됩니다. 앱의 별도 ssh 연결이 *터미널과 같은 계정*임이 확인되면 그 연결로 조용히 처리하고(터미널에 아무것도 입력되지 않음), 아니면(중첩 ssh · `su` · 비밀번호만 되는 서버) 터미널을 통해 처리합니다. 쓰기는 SHA-256 으로 검증한 뒤에만 파일을 바꾸며, 서버 파일 수정은 이 Mac 에 백업을 남기고 카드의 **"이 변경 되돌리기"** 로 복구합니다(서버에서 파일이 그 사이 바뀌었으면 되돌리지 않음).
- **안전** (서버는 이 Mac 보다 위험하다는 전제)
  - `free` · `df` · `nvidia-smi` · `systemctl status` · `docker ps` · `kubectl get` · `ip addr` 같은 **읽기 전용 점검은 바로 실행**하고, 서버를 바꿀 수 있는 명령과 모든 파일 쓰기는 **서버 이름 배지가 붙은 승인**을 받습니다(설정 → "서버 변경 명령은 승인 받기").
  - "이 세션 동안 항상 허용" 규칙은 **그 서버(user@host)에만** 적용되고 세션이 끝나면 사라집니다. "이 프로젝트에서 항상 허용(저장)" 은 서버 명령에는 제공하지 않습니다. `~/.ssh` 같은 비밀 경로는 읽지 않고, `rm -rf /` 류는 정책으로 차단합니다.
  - 비밀번호를 기다리는 중·전체 화면 프로그램(vim, top)·연결 끊김을 감지해 AI 에게 알리고, 연결이 끝나면 서버 모드는 자동으로 꺼집니다.
- **지원 셸**: bash · zsh · sh · fish · csh/tcsh. fish/csh 에서는 명령 실행·읽기·검색은 되지만 **파일 쓰기는 미지원**(명령으로 대신)입니다. 그 밖의 셸은 안내만 하고 켜지지 않습니다.

## 서버 사용량 모니터

- 접속하면 앱이 **별도의 읽기 전용 ssh 연결**로 2~10초(설정)마다 서버의 지표를 가져옵니다: CPU %, 코어 수, 부하, 메모리 사용/전체, 스왑, GPU(사용률·메모리·온도, NVIDIA 는 여러 개 지원), 디스크, 가동 시간. 값에 마우스를 올리면 자세한 툴팁이 나옵니다.
- **탭 아래 띠**가 서버, **상단 바**가 이 Mac 입니다(CPU · GPU · 가용 메모리 · 모델). 왼쪽 막대의 **서버 상태** 패널은 그래프(최근 90회 측정)와 *서버 ⇄ 이 Mac* 비교를 보여줍니다.
- 키 로그인이거나, 세션 메뉴로 연 접속(연결 공유)이면 추가 인증 없이 동작합니다. 비밀번호만 되는 서버를 터미널에서 직접 `ssh` 로 연 경우에는 별도 연결이 인증할 수 없어 "지표 없음" 과 해결 방법이 표시됩니다(세션 메뉴로 접속하거나 키 로그인을 쓰세요).
- 모니터는 서버에 **아무것도 설치하지도 쓰지도 않습니다**(`/proc`, `vm_stat`, `df`, `nvidia-smi` 를 읽는 한 번의 POSIX 스크립트). 앱 창이 가려지면 가져오기를 멈춥니다.

## 세션 관리자 (왼쪽 막대 → 서버 아이콘)

- **저장한 세션**: 이름 · 폴더(그룹) · 호스트 · 포트 · 사용자 · **키 파일 경로**(파일 선택 창, 키 내용은 읽지 않음) · **점프 호스트**(`-J`, 최대 3단) · **시작 폴더** · **X11 전달**(끔 / 안전 `-X` / 신뢰 `-Y`) · **포트 포워딩**(`-L` `-R` `-D` 를 12개까지) · 연결 유지 신호 · 연결 공유 · 메모.
- **~/.ssh/config 편집**: 패널 위쪽의 열쇠 버튼, `~/.ssh/config` 항목의 연필 버튼, 항목을 오른쪽 클릭한 메뉴의 "~/.ssh/config 편집" 중 아무거나 누르면 모달 창에서 파일을 직접 고칠 수 있습니다(항목에서 열면 그 `Host` 줄이 선택됩니다). **문법 검사**는 실제 `ssh -G` 로 하며(연결하지 않고, `Match exec` 명령도 실행하지 않습니다), 오류는 줄 번호와 함께 보여 주고 저장을 막습니다. **저장하고 반영**하면 목록에 바로 반영되고, 이전 내용은 같은 폴더에 `config.bak-시각` 으로 보관합니다(최근 5개, 권한 0600). 열어 둔 사이 다른 곳에서 파일이 바뀌었으면 덮어쓰지 않고 알려 줍니다. 심볼릭 링크로 연결된 config 는 링크를 유지한 채 대상 파일에 씁니다. AI 에게는 이 파일을 고치는 도구가 없습니다.
- **가져오기**: `~/.ssh/config` 의 `Host` 항목(`Include` 포함)을 목록에 보여주고, 한 번 눌러 연결하거나 *세션으로 가져오기* 로 편집·저장합니다. 최근 접속(`user@host:port`)도 한 번에 다시 연결합니다.
- 검색, 복제, 편집, 삭제, 우클릭 메뉴(연결 / 지금 탭에서 연결 / 편집 / 복제 / 삭제). 입력값은 **엄격한 문자 규칙**으로 검사하므로 `-oProxyCommand=…` 같은 옵션 주입이나 셸 문법이 들어간 값은 저장도 접속도 되지 않습니다.
- 저장 위치: `~/Library/Application Support/MacAIterm/ssh-sessions.json`(권한 0600, **비밀번호·키 없음**).
- **X11**: 서버의 GUI 프로그램을 이 Mac 에 띄우려면 [XQuartz](https://www.xquartz.org) 가 필요합니다(없으면 편집 창에서 안내). X11 은 GUI 앱을 *앱 안에* 그리지 않습니다. 서버의 바탕화면을 앱 안에서 보려면 아래 **원격 화면(VNC)** 을 쓰세요.

## 폴더 트리 (왼쪽 막대 → 폴더 아이콘)

위쪽이 **서버**, 아래쪽이 **이 Mac**(터미널이 있는 폴더에서 시작, 🏠 로 홈) 입니다. 각 트리에는 경로 입력줄(Enter 로 이동), 이름 필터, 위로·홈·새로고침·새 폴더·숨김 파일 표시 버튼이 있습니다. 폴더는 펼칠 때 불러오고, 심볼릭 링크는 `→ 대상` 으로 표시합니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 이 Mac → 서버로 복사 | 파일·폴더를 **드래그해서 서버 트리의 폴더에 놓기**(여러 개 선택: ⇧/⌘ 클릭) · 우클릭 **서버로 올리기** · 툴바의 업로드 버튼 |
| 서버 → 이 Mac 으로 복사 | 서버 파일·폴더를 이 Mac 트리의 폴더로 드래그 · 우클릭 **내 Mac으로 내려받기** |
| Finder 와 주고받기 | Finder 에서 서버 트리로 드래그(업로드) · 서버 파일(25 MB 이하)을 Finder 로 드래그(**가능한 범위에서 동작**: 먼저 임시 폴더에 받아 두었다가 건네며, 앱을 종료하면 지웁니다) |
| 터미널에 경로 넣기 | 트리의 항목을 터미널 위로 드래그 → 따옴표가 붙은 경로가 입력됨 · 우클릭 **경로를 터미널에 입력** / **터미널에서 이 폴더로 이동(cd)** |
| 보기·편집 | 더블클릭 또는 **미리보기** → 서버 텍스트 파일 미리보기(200 KB까지) · **AI에게 설명 요청**(그 파일이 무엇인지 AI 에게 묻기) |
| 관리 | 이름 바꾸기 · 새 폴더 · **서버에서 삭제…**(확인 후, 휴지통 없음) / 이 Mac 은 **휴지통으로** · **권한 변경(chmod)** · 경로 복사 · Finder 에서 보기 |

전송 규칙과 안전장치:

- 같은 이름이 이미 있으면 **덮어쓰기 / 이름 바꿔 저장 / 건너뛰기** 를 묻고(전체 적용 선택 가능), 임의로 덮어쓰지 않습니다.
- 파일은 **SHA-256 으로 검증**한 뒤에만 최종 이름이 됩니다(`완료 · 검증됨`). 폴더는 `tar` 스트림으로 보내고 임시 폴더에서 옮깁니다. **취소하거나 끊겨도 반쪽짜리 파일이 최종 이름으로 남지 않습니다.**
- 동시에 2개까지 전송하고, 진행률(%)·속도·취소는 아래 **전송** 목록에서 보고, 끝나면 `완료 · 검증됨` 으로 바뀝니다. 진행 중인 개수는 왼쪽 막대 폴더 아이콘의 숫자 배지로 보입니다.
- 서버 삭제는 절대 경로만 받고 `/`, 홈 폴더, `..`, 시스템 최상위 폴더(`/etc` `/usr` …)는 거부합니다.
- SFTP 서브시스템을 쓰지 않고 일반 ssh 채널로 처리하므로, SFTP 가 꺼진 서버에서도 동작합니다.

## 원격 화면 (VNC, 터미널 제목줄의 모니터 아이콘)

SSH 로 접속한 탭에서 서버의 VNC 화면을 **앱 안**에 띄웁니다. 터미널 위쪽 제목줄의 모니터 아이콘(또는 SSH 칩 → *원격 화면 열기*)을 누르세요.

- **준비**: 서버에서 VNC 서버가 켜져 있어야 합니다. 이 기능은 서버에 아무것도 설치하거나 실행하지 않습니다. 서버 안에서만 듣게 켜 두면(`x11vnc -localhost`, `vncserver -localhost yes :1` 등) 밖에서 접근할 수 없어 더 안전합니다.
- **포트**: 보통 5900 + 화면 번호입니다(`:1` 은 5901). 마지막으로 쓴 포트는 서버별로 기억합니다.
- **연결 방식**: 화면 데이터는 이 탭의 SSH 연결 안으로만 흐릅니다(`ssh -W`). 이 Mac 에 포트가 열리지 않고, 새 로그인도 만들지 않습니다(키 로그인 또는 *연결 공유* 를 켠 세션).
- **비밀번호**: VNC 서버가 비밀번호를 요구하면 창이 열리고, 입력한 값은 그 연결에만 쓰이며 저장하지 않습니다. 이 앱의 AI 에는 화면이 전달되지 않습니다.
- **도구 모음**: 터미널로 돌아가기(연결은 유지됩니다), 포트와 연결 / 끊기, 창에 맞춤 / 원본 크기, 화질(빠르게 · 균형 · 선명하게), 보기만, Ctrl+Alt+Del, Mac 클립보드를 서버로 보내기, 서버 클립보드를 Mac 으로 복사(자동으로 덮어쓰지 않음), 전체 화면.
- **접속하면 자동으로 열기**: 도구 모음의 체크박스를 켜 두면, 그 서버에 SSH 로 접속해 로그인이 끝난 뒤 원격 화면이 자동으로 열리고 기억해 둔 포트로 연결합니다(서버마다 따로 기억). 서버의 VNC 가 아직 켜지는 중이면 4초 간격으로 최대 5번 기다렸다가 다시 시도하고, 그래도 안 되면 "다시 연결" 버튼이 남습니다. VM 을 켤 때 VNC 서버도 같이 켜지게 하려면 서버에서 서비스로 등록해 두세요(`systemctl --user enable --now` 로 `vncserver -localhost yes :1` 을 실행).
- **AI 채팅은 이 화면과 다르게 동작합니다.** AI 는 원격 화면을 보지도 클릭하거나 입력하지도 못합니다(화면 이미지는 모델에 전달되지 않습니다). 채팅 요청은 평소처럼 SSH 셸의 명령으로 실행되고, 결과는 오른쪽 채팅 카드에 나옵니다. 예를 들어 "terminal 창을 열어 whoami 를 입력해"라고 하면 창을 열지 않고 `whoami` 를 셸에서 실행합니다. 서버에서 작업하게 하려면 아래쪽 **원격** 스위치를 켜세요. 터미널은 원격 화면 뒤에 가려져 있으니 직접 보려면 도구 모음의 **터미널** 버튼을 누르세요. 키보드 입력은 포커스가 있는 곳으로 갑니다: 화면을 누르면 서버 데스크톱으로, 아래 입력창을 누르면 AI 로 갑니다.
- 탭을 닫거나 SSH 가 끝나면 화면과 연결이 함께 정리됩니다.

## 설정 (설정 → SSH · 원격)

| 항목 | 기본 | 설명 |
|---|---|---|
| SSH 접속 시 AI 연결 | 물어보기 | 접속을 감지했을 때 AI 를 서버로 전환할지(물어보기 / 자동 전환 / 안 함) |
| 서버 변경 명령은 승인 받기 | 켬 | 끄면 서버에서도 일반 권한 모드 규칙을 따릅니다(권장하지 않음) |
| 서버 CPU·메모리·GPU 표시 | 켬 | 탭 아래 서버 띠와 상태 패널 |
| 서버 지표 갱신 주기 | 3초 | 2 / 3 / 5 / 10 초 |
| 연결 유지 신호 | 켬 | 세션 메뉴로 여는 접속에 `ServerAliveInterval=30` |
| 연결 공유 | 켬 | 세션 메뉴로 연 접속을 파일 패널·모니터가 함께 씀(비밀번호를 한 번만 입력) |
| 접속 시 파일 패널 | 자동 | SSH 를 감지하면 왼쪽에 폴더 트리를 자동으로 엶 |

## 보안 설계

- **비밀번호·키 암호·개인 키는 받지도 저장하지도 않습니다.** 별도 연결은 항상 `BatchMode=yes` 라 프롬프트를 띄울 수 없습니다.
- 앱은 **사용자가 연 연결을 끊지 않습니다.** 사용자의 마스터 연결은 재사용(`ControlMaster=no`)만 하고, `-O exit` 는 앱이 직접 만든 연결에만 보냅니다.
- 호스트 키가 바뀐 경우·접속 거부 등은 타임라인에 지문과 함께 경고로 표시합니다. 호스트 키 질문에 앱이 대신 답하지 않습니다.
- 서버에서 읽은 출력·파일 내용은 *신뢰할 수 없는 데이터*로 다룹니다(파일이 AI 에게 지시할 수 없음). 비밀 패턴은 모델에 보내기 전에 가려지고, 터미널 제어 문자는 제거됩니다.
- 저장 파일(`ssh-sessions.json`, `ssh-recent.json`)에는 이름·호스트·키 파일 *경로*만 있습니다([PRIVACY.md](../PRIVACY.md)).

## 알려진 한계

- 시험은 이 Mac 의 임시 `sshd`(키 로그인) 기준입니다. 실제 리눅스 서버·GPU 서버에서의 모든 조합을 검증한 것은 아닙니다.
- AI 가 서버에서 실행하는 명령은 사용자의 터미널에 **그대로 입력되어 보입니다**(투명성을 위해). 앞에서 말한 조용한 연결을 쓸 수 없는 경우의 파일 도구는 긴 도우미 스크립트가 터미널에 보입니다.
- **로컬 네트워크 권한(macOS)**: 같은 공유기 안의 서버(`192.168.x.x` 등)에 앱 터미널에서만 `No route to host` 가 나고 다른 터미널에서는 되면, macOS 가 이 앱에 "로컬 네트워크" 접근을 허용하지 않은 것입니다. 허용은 앱의 식별자(번들 ID)별로 기록되어, 앱 이름이나 식별자가 바뀌면 새 앱으로 취급되어 다시 허용해야 합니다. 시스템 설정 > 개인정보 보호 및 보안 > 로컬 네트워크에서 MacAIterm 을 켜세요. 목록에 MacAIterm 이 아직 없으면 설정 > SSH · 원격 의 **로컬 네트워크 허용 > 허용 요청** 을 누르세요. 앱이 직접 로컬 네트워크에 한 번 접근해서 macOS 의 허용 창이 뜹니다(창은 한 번만 뜨고, 이미 답했다면 뜨지 않습니다). 서버와 다른 네트워크(Wi-Fi/LAN)에 있으면 접속이 `Operation timed out` 으로 끝나며, 앱이 "이 Mac은 … 네트워크에 있어 … 서버와 같은 네트워크가 아닌 것으로 보입니다" 라고 알려 줍니다. 앱의 접속 시도는 10초 안에 끝나며(`ConnectTimeout=10`), 본인의 ssh 설정에 `ConnectTimeout` 이 있으면 그 값을 씁니다. 목록에 없거나 켜도 안 되면 터미널에서 `/Applications/MacAIterm.app/Contents/MacOS/MacAIterm` 로 앱을 실행하세요(허용 책임이 그 터미널로 넘어가 접속됩니다). 사설 주소에서 `No route to host` 가 나면 앱이 스스로 짧게 한 번 접속을 시도해 macOS 가 허용 창을 띄우게 합니다(이미 거부해 둔 경우에는 뜨지 않습니다). 같은 Electron 버전으로 만든 앱은 실행 파일의 내부 UUID 가 같고, macOS 가 허용을 이 UUID 로 적용하기 때문에, 이미 답을 받은 다른 앱과 UUID 를 나눠 쓰면 허용 창이 뜨지 않고 조용히 막힐 수 있는 것으로 보입니다(원인을 확정하지는 못했습니다. 이 앱은 빌드할 때 실행 파일마다 고유한 UUID 를 붙였고, 그 뒤에 허용 창이 떴습니다).
- 비밀번호만 되는 서버: 직접 연 접속에서는 모니터·파일 패널이 인증할 수 없습니다(세션 메뉴로 접속하거나 키 로그인). 터미널 안에서 또 다른 서버로 `ssh` 하는 중첩 접속은 바깥쪽 서버를 기준으로 보여줍니다.
- Finder 로 끌어내기는 최대 25 MB 파일, 가능한 범위에서만 동작합니다. 서버 → Finder 가 안 되면 서버 → 이 Mac 트리 드래그나 "내려받기" 를 쓰세요.
- X11 은 XQuartz 가 필요하고, GUI 프로그램은 XQuartz 창으로 열립니다. Windows 서버는 대상이 아닙니다.
- 원격 화면(VNC)은 가짜 VNC 서버와 임시 `sshd`, 그리고 Ubuntu VM 의 TigerVNC 서버(로컬 VM)로 시험했습니다. 다른 VNC 서버(x11vnc 등)와 느린 회선에서의 화질, 지연은 확인하지 못했습니다. 소리, 파일 전송, 여러 모니터 선택은 지원하지 않고, Cmd 키 조합은 앱 메뉴가 먼저 받아 서버로 가지 않을 수 있습니다.
