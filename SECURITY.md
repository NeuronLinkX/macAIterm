# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's [private vulnerability reporting](https://github.com/NeuronLinkX/macAIterm/security/advisories/new) (Security tab, then **Report a vulnerability**). The report is visible only to the maintainers.

Start with a description and the steps to reproduce. Do not include credentials, API keys or private server details.

## Supported versions

Only the latest release receives fixes.
